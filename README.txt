BARBOSA FPS — AIM TRAINER
=========================

Como abrir:
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Execute com Live Server ou use um servidor HTTP local.
4. Abra index.html no Chrome, Firefox ou Edge com WebGL2 ativado.

Controles:
WASD mover | Shift correr | Mouse mirar | Clique esquerdo disparar
R recarregar | Espaço pausar | ESC liberar mouse

A entrada foi renovada com o brasão enviado do Colégio Estadual Barbosa Ferraz,
identidade visual azul, configurações de treino e ajustes de mira. As imagens
das armas estão na pasta assets.

Se o navegador bloquear WebGL ao abrir o arquivo diretamente, use Live Server.
